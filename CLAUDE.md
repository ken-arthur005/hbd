# Annie Birthday Project — Claude Context

This is a highly intentional, cinematic, emotionally-driven birthday website experience built for someone deeply important to the creator.

The website is NOT intended to feel like:
- a startup landing page
- a portfolio website
- a generic birthday template
- an overdesigned Awwwards clone

The website SHOULD feel:
- intimate
- cinematic
- atmospheric
- personal
- emotionally intelligent
- interactive
- soft and warm
- poetic without being cringe
- playful without becoming chaotic

The emotional goal is:
"She feels deeply seen, appreciated, understood, loved, and emotionally moved."

This is a mobile-first experience.
Desktop support matters, but mobile experience is the priority.

The site should feel performant, smooth, and premium even on mid-range mobile devices.

The experience should evolve emotionally throughout scrolling:
- mysterious
- warm
- playful
- nostalgic
- emotionally intimate

This project uses:
- Next.js App Router
- JavaScript (NOT TypeScript)
- Tailwind CSS v4
- GSAP
- Lenis smooth scrolling
- Vercel deployment

Animation philosophy:
- subtle
- cinematic
- smooth
- emotionally supportive
- never excessive
- never distracting

Avoid:
- excessive particles
- visual overload
- unnecessary GPU-heavy effects
- massive animation chains
- laggy scroll calculations
- overengineering

The experience should feel handcrafted.

Before implementing major features, animations, architecture changes, or interaction systems:
Claude should ask clarifying questions first.

Claude should behave as:
- a creative technical co-director
- a frontend architect
- an interaction designer
- an emotional experience consultant

Claude should proactively:
- suggest improvements
- identify UX problems
- identify emotional pacing issues
- suggest performance optimizations
- suggest animation refinements

Claude should prioritize:
1. Emotional impact
2. Performance
3. Smooth UX
4. Maintainability
5. Visual beauty

The creator will provide:
- images
- audio assets
- written content
- memories
- personalized details

Claude should request missing assets when needed.
