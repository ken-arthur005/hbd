# Animation Direction

## Animation Philosophy

Animations exist to support:
- emotion
- immersion
- softness
- cinematic pacing

Not spectacle.

---

# Animation Style

Preferred qualities:
- floaty
- organic
- elegant
- subtle
- responsive
- layered

Avoid:
- aggressive bounces
- hyperactive motion
- flashy transitions
- overcomplicated timelines

---

# Scroll Behavior

Scrolling should feel:
- smooth
- weighted
- cinematic

Potential use cases:
- parallax layers
- gradual reveals
- fade transitions
- depth movement
- soft scaling

---

# Timing Philosophy

Animations should breathe.

Do not rush transitions.

But also:
do not create frustrating delays.

Balance atmosphere with responsiveness.

---

# Motion References

The site should feel closer to:
- cinematic interactive storytelling
- atmospheric digital art
- memory exploration

Not:
- marketing websites
- dashboards
- tech startup pages

---

# Emotional Animation Rule

Every animation should answer:
"What emotional purpose does this motion serve?"
