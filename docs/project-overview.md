# Project Overview

## Project Type

A cinematic interactive birthday website experience.

Built as a one-page storytelling experience optimized primarily for mobile devices.

The site is intended to feel like:
- an emotional journey
- a memory archive
- a playful interactive documentary
- a digital love letter

The experience is deeply personalized around Annie's personality.

---

# Core Themes

- Nature
- Books
- Quiet intelligence
- Hidden softness
- Emotional intimacy
- Nostalgia
- Warm humor
- Intentionality
- Memory
- Observation

---

# Artistic Direction

The experience should feel:
- cozy
- poetic
- cinematic
- atmospheric
- elegant
- handcrafted

Visual references:
- woodland atmosphere
- soft academia
- paper textures
- cinematic lighting
- floating memories
- analog warmth

---

# Technical Goals

- Smooth scrolling
- High performance
- Mobile-first responsiveness
- Cinematic transitions
- Lightweight assets
- Optimized animations

The site should feel premium without becoming heavy.

---

# Emotional Goals

The website should make Annie feel:
- deeply appreciated
- emotionally understood
- genuinely loved
- observed in meaningful ways
- emotionally safe
- nostalgic
- surprised
- amused
- emotionally overwhelmed in a good way

The experience should feel increasingly personal as the user scrolls deeper.

---

# User Journey

The emotional pacing should roughly follow:

1. Curiosity
2. Wonder
3. Familiarity
4. Humor
5. Nostalgia
6. Emotional intimacy
7. Heartfelt conclusion

---

# Core Rule

Specificity creates emotional impact.

The site should avoid generic compliments and generic emotional writing.

Observational details matter more than dramatic language.
